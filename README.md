# Alpha Numworks

This is a port of [alpha OS](https://AlphaNumworks/Alpha)'s `alpha` micropython module,
so you can dev some scripts on your computer and they will work on your Alpha Calculator.

This script depends of `kandinsky` and `ion-numworks`. However, this two module will mostly be used
alongside `alpha-numworks` by you to make your game.
